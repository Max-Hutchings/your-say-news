# Plans

One implementation plan per feature, written **before** building it.

Each plan should cover: the goal, affected domains/services, API/DTO changes, DB migrations and
seed data, frontend pages/components, and the test approach. Name files in kebab-case after the
feature (e.g. `vote-on-post.md`).
